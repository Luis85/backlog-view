# What has no evidence

The four gaps the backward read exposes: opportunities with no evidence, features with no
evidence, evidence linked to nothing, and the items resting on far more evidence than
anything else. None of them is an error — some work needs no argument — so each is listed
and counted rather than flagged.

**Outcome** — The parts of the plan resting on nobody's observation stop being invisible.
