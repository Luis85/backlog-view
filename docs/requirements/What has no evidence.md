# What has no evidence

The four gaps the backward read exposes: opportunities with no evidence, features with no
evidence, evidence linked to nothing, and the items resting on the most evidence. None of
them is an error — some work needs no argument — so each is listed and counted rather than
flagged.

The first three are a count of zero and need nothing else said. **The fourth is a ranking,
not a threshold**: the items with the most linked evidence, ordered by that count, longest
first, showing the count beside each. There is deliberately no line above which an item is
"heavily supported" — 10, 7 and 4 have no natural cut, and any of a fixed number, the maximum
or a statistical spread would list different items in different vaults while sounding like a
fact about the evidence. A ranked list is the same information with nobody's threshold in it,
and the reader draws the line where they see it.

**Outcome** — The parts of the plan resting on nobody's observation stop being invisible.
