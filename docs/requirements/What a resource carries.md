# What a resource carries

Three properties on the resource's own note — how much capacity they have, what they do, and
whether they are still on the team — each one a key this view names and the user maps, exactly
like every other optional property ([[Suggested property names, mapped by the user]]).

Each is optional in the same shape the rest are: unnamed means unread and unwritten, and
absence is a value ([[Backfill missing properties]]). Nothing here is required for a resource
to exist — a note with a type and a name is a whole resource, and each property adds one fact
to what the view can show about it.

**Outcome** — A resource note answers how much they can take on, what they do and whether they
are still here, and the view reads those answers instead of the reader remembering them.
