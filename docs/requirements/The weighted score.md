# The weighted score

The sum of score times weight, normalized to the scale's own range, recomputed the instant
any input changes and written back to the note with its model stamp. Weights must total
100, and a partial profile follows the rule this epic's fifth open question settles.

**Outcome** — One comparable number per item, derived the same way for every item.
