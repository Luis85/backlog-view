# Evidence as a link from the item

A backlog or discovery item names its evidence in one property — a list of links to notes
in the vault — under a key the vault chooses. Reading it forward gives the argument for the
item; reading every item's answers gives the backward index the rest of this epic is built
on.

**Outcome** — The reasons for a piece of work are one property away from the work.
