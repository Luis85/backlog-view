# Dependencies as a table

The same edges as rows — item, what it depends on, what it blocks, and the state of each
dependency — because a table is sortable, filterable, searchable and readable on a narrow
pane, and a graph is none of those.

**Outcome** — The dependencies can be worked through as a list, not only looked at.
