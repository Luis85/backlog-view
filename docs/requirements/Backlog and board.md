# Backlog and board

One view, two projections: a toolbar toggle switches the tree to a board and back, the
mode persists per saved view, and everything that guards the tree — the write gate, the
context-row rule, undo — guards the board unchanged.

**Outcome** — The same backlog can be read as a tree or as a board, and choosing costs
nothing: no second data model, no second configuration, no information left behind in
the projection you are not looking at.
