# Design debt

Deferred design improvements are classified rather than lost — an activity value like any
other, surfaced beside the technical and product work already in the backlog, so a team can
see what it chose not to do.

**Outcome** — Design debt accumulates somewhere a planning conversation can reach it.

*Barebones. The open question is whether this needs anything at all beyond a saved view over
the activity property: if it does not, this feature closes as already delivered by the two
above it.*
