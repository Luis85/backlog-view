# Scheduling work

The roadmap's write axis: schedule from the shelf, slide and resize bars, unschedule
back, and set the same properties from a row in any projection — every gesture a planned
frontmatter write through the one gate, previewed before it lands, and matched by
keyboard and menu equivalents throughout, because a plan that can only be moused is a
plan some people cannot make.

**Outcome** — Scheduling is ordinary backlog editing: what a gesture will write is
shown before it is written, it applies through the same gate as every other write, one
undo takes it back — and none of it is pointer-only or roadmap-only.
