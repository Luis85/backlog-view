# Activity, under a discipline

A second, finer property says what kind of work it is within its discipline — research,
interaction design, wireframe, prototype, usability test, design review, design debt — again
from a vocabulary the vault configures rather than one the plugin ships.

**Outcome** — Two UX tasks against the same Feature can be told apart without opening
either.

*Barebones. Whether an activity vocabulary is scoped per discipline or shared across all of
them is the first question its use cases have to answer.*
