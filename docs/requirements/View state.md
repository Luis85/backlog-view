# View state

What the view remembers between sessions, and what it deliberately does not: which rows
are open, and how the columns fit the pane.

**Outcome** — The view opens where it was left, and fits the pane it is given.

## Use cases

- [[Collapse persistence]] — which rows are open, remembered per base and view.
- [[Property columns]] — the Base's properties as aligned columns, tags editable.
