# Levels above the epic

A vault may declare grouping levels above its work ladder — portfolio, product, domain —
each an ordinary note that work points at or hangs from, and each optional. A vault that
declares none sees no portfolio anywhere.

**Outcome** — Higher-order structure exists for the vaults that have it and for no others.
