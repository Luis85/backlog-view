# Comparing across products

Portfolio items are compared on the **stored** value score — the property an estimation view
wrote, read here under a key this view names, beside the effort and confidence properties it
names for itself. That is the whole handoff, and it is deliberately the only one: the model
that produced a score lives in an estimation view's own settings, which this view may not
read and must not require to exist.

So a portfolio comparison is honest about what it is showing. A score written under a
different model is a different measurement, and the stamp beside it says so; where two
products were scored by two models, the comparison names that rather than averaging across
it. Rescoring a cross-product population under one model is what an estimation view over
that population is for.

**Outcome** — Investment choices between products use the same recorded numbers everyone
else sees, and a comparison across two different models says so instead of pretending to
be one.
