# Comparing across products

Selected portfolio items can be scored and compared by the estimation model, so an
investment decision between two products uses the same dimensions as one inside a product.
Nothing about the model changes; only the population does.

**Outcome** — Cross-product choices are made with the same explicit criteria as everything
else.
