# Progress tracking

Reading a workflow state off each note and rolling it up the tree, so a parent shows how
much of its subtree is finished without anyone maintaining a percentage.

Entirely optional: with no state property configured, none of it renders.

**Outcome** — A parent says how much of it is done without anyone maintaining a
percentage.

## Use cases

- [[Workflow state]] — move an item to In progress or Done from the row.
- [[Rollups and hiding finished work]] — counts up the tree, and finished branches out of
  the way.
