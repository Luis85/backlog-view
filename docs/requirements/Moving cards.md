# Moving cards

Dragging a card to another column is the state chip's write made spatial: one planned
batch through the same gate, one undo, and the menu as the path that works everywhere a
drag cannot. Nothing about moving cards invents a new write path.

**Outcome** — Work advances by moving it, on any device and by any input, and every move
is a frontmatter write that can be taken back.
