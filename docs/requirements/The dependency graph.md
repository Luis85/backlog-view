# The dependency graph

Items as nodes, edges as the dependencies between them, laid out so a chain can be followed
and a knot can be seen. Selecting a node opens the item; the view draws what the base
returned and nothing else.

**Outcome** — The shape of the sequencing is visible in one picture.
