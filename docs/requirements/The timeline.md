# The timeline

The dated axis: bars from a start and a target property, spans inherited upward where
parents are silent, and time navigation that stays inside the pane. Every date on
screen is a date some note states — or is styled as the inference it is, the rule the
surveyed trackers converge on.

**Outcome** — Items with dates read as a plan on a calendar, parents summarize their
children without copied dates that drift, and no rendering decision ever writes a date
anywhere.
