# Assignment

Reading who an item is assigned to off each note, from a property this view names, and
letting that answer be changed without leaving the backlog.

Optional in ONE half rather than [[Risk management]]'s two, and the difference is the
whole shape of the feature: with no property named nothing is read or written, and there
is no second list to configure, because the names on offer are the ones the base's own
results already carry, plus whatever the user types. Nobody declares who exists.

**Outcome** — A row says who is on it, and changing that answer is one click from the row
it is on.
