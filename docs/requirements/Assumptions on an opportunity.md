# Assumptions on an opportunity

An opportunity carries the assumptions it rests on — value, usability, feasibility,
viability — as notes linked to it, each one a thing that can be tested and found wrong.
The categories are a suggested vocabulary the vault can replace.

**Outcome** — What a plan depends on being true is written down before it is discovered by
building the wrong thing.
