# Prioritization

Reading how important each item is off a property this view names, from a ladder the view
options declare, and letting it be set from the row it is on.

Shipped prefilled with MoSCoW — `1 - Must`, `2 - Should`, `3 - Could`, `4 - Won't` —
because that is the vocabulary most backlogs already rank with, numbered so a list sorts
the way it reads. The words stay the reader's: a different ladder typed into the option is
the ladder the menu offers.

Optional in the same two independent halves [[Risk management]] is: with no property named
nothing is read or written, and with the ladder cleared the property is still backfilled
and edited in Obsidian's own property editor — there is simply nothing for this view to
offer.

**Outcome** — An item says how important it is, in the reader's own words, and changing
that answer is one click from the row it is on.
