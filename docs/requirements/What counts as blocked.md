# What counts as blocked

An item is blocked when something it depends on has not reached a state the vault declares
sufficient. The rule is configuration — which states clear a dependency — and the answer is
derived on read, never written to the blocked item.

**Outcome** — Blocked means one stated thing, and the same items are blocked for everyone.
