# Discipline as a configured property

An item says which craft owns the work, in one property, under a key the vault names, from
a vocabulary the vault configures — product, ux, requirements, engineering, qa, or whatever
a team actually has. Setting it is a planned, gated, undoable write like any other.

**Outcome** — Which discipline does a piece of work is written down, so it can be asked of
the backlog instead of remembered.

*Barebones. The use cases under it are not written yet: the vocabulary's configuration
shape, the write and its menu, and what an unconfigured key does are each still open.*
