# Feature as a legal parent for Task

`Task` gains `Feature` as a legal parent, for everyone and unconditionally, because the
research a designer does before any PBI exists has no PBI to hang from. It is the one
structural change this epic makes, and it is deliberately not conditional on a discipline:
legality that read an optional property would make the same note legal and illegal as one
key is set and cleared.

**Outcome** — Work that precedes a PBI has somewhere legal to live, and stops being a loose
note the tree cannot see.

*Barebones. It touches the register's own gate and hierarchy table, what a menu offers, and
the ladder rule that a child sits one rung below its parent — the rung skip has to be stated
rather than inherited. No other pair is reopened.*
