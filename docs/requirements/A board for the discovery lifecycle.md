# A board for the discovery lifecycle

Ideas, opportunities, problems, assumptions and experiments draw as cards in columns named
by the lifecycle this view declares, moved between them by drag, by keyboard and from the
card's own menu — one move, three inputs, one gated write, the way a board card already
moves.

**Outcome** — The state of every candidate is visible at once, and changing it is a drag.
