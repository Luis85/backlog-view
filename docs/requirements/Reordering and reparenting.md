# Reordering and reparenting

Changing the tree by moving things: drag a row between two others to rank it, drop it onto
a row to re-parent it, or use the keyboard and menu when dragging is impractical.

Every move writes frontmatter, so the change is in the notes rather than in a view's memory
— and is visible to every other tool that reads them.

**Outcome** — The backlog can be reshaped by moving rows, and every move is in the notes
rather than in a view's memory.
