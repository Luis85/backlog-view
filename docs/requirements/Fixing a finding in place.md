# Fixing a finding in place

Where a repair is unambiguous — assign the missing type, initialize a property, set a
parent, assign a release, archive a stale item — the finding offers it as one gated,
undoable write. Where it is not unambiguous, nothing is offered: a guessed repair is worse
than a listed problem.

**Outcome** — The cheap half of backlog hygiene takes one click and can be taken back.
