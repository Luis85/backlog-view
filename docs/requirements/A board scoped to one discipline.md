# A board scoped to one discipline

A board whose scope is a discipline, with a workflow of its own falling back to the
requirements board's field by field — the same shape the Deliverables board and the
iteration board already have, so this is [[Product Kanban]]'s board with a scope rather than
a second board.

**Outcome** — A designer runs their own workflow — planned, research, designing, review,
validating, done — without leaving the backlog the rest of the team plans from.

*Barebones. What it inherits from the existing boards (WIP limits, column policies, date
stamps, "show completed items") is undecided, and each of those was a deliberate yes or no
for the Deliverables board.*
