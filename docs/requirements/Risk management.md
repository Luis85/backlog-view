# Risk management

Reading a risk level off each note, from a property this view names and a vocabulary the
view options declare, and letting it be set without leaving the backlog.

Entirely optional, and optional in two independent halves: with no property named nothing
is read or written, and with the levels cleared the property is still backfilled and
edited in Obsidian's own property editor — there is simply nothing for this view to offer.

**Outcome** — An item says how risky it is, in the reader's own words, and changing that
answer is one click from the row it is on.
