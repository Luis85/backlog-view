# A release is a note of its own

A release is an ordinary note with a type of its own, carrying its version, its target date
and its status. It hangs from nothing and holds nothing itself — **membership is a property
on the work**, naming the release — so a release can be planned before anything is in it.

That is not how a milestone works, and the difference is worth stating because the two look
alike on a roadmap: a milestone holds no work and nothing points at it either, which is why
there is no item-side milestone property anywhere in this register.

**Outcome** — A release exists as a thing to link to, with its own dates and its own state.
