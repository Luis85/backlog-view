# Weighting scenarios

Alternative weightings — growth, compliance, retention, cost — applied to the same scores to
see what each one would rank first. A scenario changes no property and writes no total; the
screen says which scenario is on it, and the stored value stays the one the view's own model
produced.

**Outcome** — "What would this look like if we cared most about X" is answerable without
rewriting anything.
