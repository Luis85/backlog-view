# Item Templates

A new item can start from a saved template — its body and its extra frontmatter — instead
of a blank note, and templates themselves are created and maintained from inside the
plugin rather than by hand-editing a note into the right shape.

**Outcome** — Someone creating an item can optionally pick a template for the type they
are creating, see and edit its body before the note exists, and get the template's extra
frontmatter along with it — and anyone can add a new template, or turn an existing item
into one, without leaving the view.

Specification only — nothing under this feature is built yet.
