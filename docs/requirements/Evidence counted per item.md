# Evidence counted per item

For a selected item, its evidence summarized by kind — how many customer requests, support
incidents, interviews, analytics observations — derived from the linked notes and their own
kind property, never from a number anybody maintains by hand.

The kind property is a key this view names for itself, beside the vocabulary of kinds:
configuring the words without naming the field is a list with nowhere to look. Unconfigured,
the summary counts the evidence and does not break it down, which is the honest partial
answer rather than a guess at which field holds the kind.

**Outcome** — The argument for a feature can be summarized in a line without losing what it
is made of.
