# An inbox for raw ideas

A capture surface that asks for as little as possible: a title, optionally a description,
tags, a source, a date, **an author and any related notes**. Anything captured lands in the
first lifecycle state and is findable there; nothing else is required of it, because an inbox
that demands fields is an inbox nobody uses.

Every one of those but the title is a key this view names and an ordinary property when it is
bound — the author a plain value, the related notes a link property like every other. They
are offered because who said it and what it sits beside are the two things nobody can
reconstruct later: a tag can be added next week, a source cannot be remembered. Unbound, the
field is not shown, which is the same rule as everywhere else and is why offering them costs
the fast path nothing.

**Outcome** — An idea can be written down in the seconds it takes to have it.
