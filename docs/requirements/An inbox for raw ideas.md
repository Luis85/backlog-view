# An inbox for raw ideas

A capture surface that asks for as little as possible: a title, optionally a description,
tags, a source and a date. Anything captured lands in the first lifecycle state and is
findable there; nothing else is required of it, because an inbox that demands fields is an
inbox nobody uses.

**Outcome** — An idea can be written down in the seconds it takes to have it.
