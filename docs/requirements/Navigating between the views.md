# Navigating between the views

An item selected in one view can be opened in another view that has something to say about
it — its evidence, its score, its release, its dependencies — where such a view exists in
the same base. Where none exists, nothing is offered: this navigates between views a vault
actually has, and never advertises a capability nobody added.

**Outcome** — The views feel like one product without any of them depending on another.
